Recursividad

Definición Procedimientos Características Complejidad Factorial Fibonacci Hanói Fractales Fuentes

1. Definición

La recursividad es una forma de resolver un problema usando soluciones de versiones más pequeñas del mismo problema [1]. Una función recursiva tiene un caso base (respuesta directa) y un caso recursivo (se llama a sí misma) [1][7].

factorial(n):
  si n == 0: devolver 1          // caso base
  devolver n * factorial(n-1)    // caso recursivo

2. Procedimientos recursivos y aplicaciones

Un procedimiento recursivo se llama a sí mismo hasta llegar al caso base y después regresa con los resultados [6]. Se usa en:

  • Cálculos matemáticos (factorial, Fibonacci).
  • Listas y árboles [6].
  • Búsqueda binaria y mergesort [5].
  • Torres de Hanói y fractales.

3. Características

  • Caso base: es la condición para parar. Sin él la recursión es infinita [7].
  • Caso recursivo: la función se llama con un problema más pequeño.
  • Avance: cada llamada debe acercarse al caso base [7].
  • Pila de llamadas: cada llamada pendiente usa memoria [3].

4. Complejidad computacional

Para medir un algoritmo recursivo se escribe una relación de recurrencia T(n) y se resuelve [5]. Por ejemplo, Hanói cumple T(n) = 2T(n-1) + 1, que da 2n - 1 movimientos [2][5].

AlgoritmoRecurrenciaTiempo
FactorialT(n) = T(n-1) + 1O(n)
Fibonacci (simple)T(n) = T(n-1) + T(n-2)O(2n) [8]
HanóiT(n) = 2T(n-1) + 1O(2n) [3]
Búsqueda binariaT(n) = T(n/2) + 1O(log n) [5]
