1. Definición de recursividad

La recursividad es un método para resolver un problema cuya solución depende de soluciones a instancias más pequeñas del mismo problema [1]. Se considera una de las ideas centrales de las ciencias de la computación.

Una definición recursiva siempre tiene dos partes: uno o más casos base (entradas con respuesta directa) y uno o más casos recursivos (donde la función se llama a sí misma con una entrada más simple) [1][7].

factorial(n):
  si n == 0: devolver 1            # caso base
  devolver n * factorial(n - 1)    # caso recursivo

2. Procedimientos recursivos y aplicaciones

Un procedimiento recursivo es aquel que se invoca a sí mismo, directa o indirectamente, hasta alcanzar el caso base; luego las llamadas "se desenrollan" devolviendo resultados [6][8]. Se usa mucho con estructuras que se definen recursivamente: una lista es vacía o un elemento seguido de otra lista [6].

  • Matemáticas: factorial, Fibonacci, potencias.
  • Estructuras de datos: recorrer listas y árboles (por ejemplo, árboles binarios).
  • Divide y vencerás: búsqueda binaria y ordenamiento por mezcla (mergesort) [5].
  • Rompecabezas y gráficos: Torres de Hanói y fractales.

3. Características de la recursividad

  • Caso base: condición de parada; sin ella hay recursión infinita y desbordamiento de pila (stack overflow) [7].
  • Caso recursivo: la función se llama con un problema más pequeño [6].
  • Progreso: cada llamada debe acercarse al caso base [7].
  • Autorreferencia: la función aparece en su propia definición [6].
  • Pila de llamadas: cada llamada pendiente ocupa memoria; la profundidad determina el espacio usado [3].

4. Complejidad computacional

Para analizar un algoritmo recursivo se escribe una relación de recurrencia T(n) con el costo de las llamadas más el trabajo extra, y luego se resuelve [5][4]. Ejemplos de las fuentes: mergesort cumple T(n)=2T(n/2)+n y la búsqueda binaria T(N)=1+T(N/2) [5]; Hanói cumple T(n)=2T(n−1)+1, lo que da 2ⁿ−1 movimientos [2][3][5].

7. Torres de Hanói

Para mover n discos de A a C: mueve n−1 discos a B, mueve el disco mayor a C y mueve los n−1 discos de B a C [2]. Reglas: un disco a la vez y nunca uno grande sobre uno pequeño. Mínimo: 2ⁿ−1 movimientos [3].
